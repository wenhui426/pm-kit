当前调度原则

当前 Agent 根据目标和已有材料选择能力。阶段产物交接后可继续、跳过或重新编排；发生方向冲突时由用户选路。

入口方式

截图、HTML、文档和文字都进入 pm-kit。当前 Agent 读取唯一 SKILL.md 后开始调度。

链路方式

能力清单按目标组合；内嵌专项模块按需读取。用户可指定路径，冲突时确认后继续。

资源扩展

场景、组件、模板和脱敏案例分为内置与本地目录。本地资源可持续新增，通过清单、版本和校验规则参与任务。
