# BPMN 2.0 元素详解

## 流对象 (Flow Objects)

### 事件 (Events)

事件表示流程中发生的某些事情，分为三类：

| 类型 | 符号 | 描述 |
|------|------|------|
| 开始事件 | 单边细线圆 | 流程的触发点 |
| 中间事件 | 双边细线圆 | 流程中的等待或触发 |
| 结束事件 | 单边粗线圆 | 流程的终止点 |

### 事件触发器类型

| 触发器 | 图标 | 用途 |
|--------|------|------|
| 无 (None) | 空白 | 通用开始/结束 |
| 消息 (Message) | 信封 | 消息触发 |
| 定时器 (Timer) | 时钟 | 时间触发 |
| 错误 (Error) | 闪电 | 错误处理 |
| 信号 (Signal) | 三角 | 信号广播 |
| 终止 (Terminate) | 实心圆 | 立即终止所有流程 |
| 补偿 (Compensation) | 双箭头 | 补偿回滚 |
| 条件 (Conditional) | 文档 | 条件满足时触发 |
| 链接 (Link) | 箭头 | 跨页连接 |
| 取消 (Cancel) | X | 取消事务 |
| 升级 (Escalation) | 向上箭头 | 升级处理 |

### 活动 (Activities)

活动是流程中的工作单元：

#### 任务类型

| 任务类型 | 图标 | 描述 |
|----------|------|------|
| 抽象任务 | 无 | 通用任务 |
| 用户任务 | 人形 | 需要人工完成 |
| 服务任务 | 齿轮 | 自动化服务调用 |
| 脚本任务 | 文档 | 执行脚本 |
| 业务规则任务 | 表格 | 执行业务规则 |
| 发送任务 | 黑信封 | 发送消息 |
| 接收任务 | 白信封 | 接收消息 |
| 手动任务 | 手形 | 无系统参与的人工任务 |

#### 子流程类型

| 子流程类型 | 描述 |
|------------|------|
| 嵌入式子流程 | 在父流程中展开显示 |
| 调用活动 | 引用全局定义的流程 |
| 事件子流程 | 由事件触发的子流程 |
| 事务 | 支持补偿的原子操作组 |

#### 任务标记

| 标记 | 符号 | 描述 |
|------|------|------|
| 循环 | 循环箭头 | 重复执行 |
| 多实例并行 | 三竖线 | 并行执行多个实例 |
| 多实例串行 | 三横线 | 顺序执行多个实例 |
| 补偿 | 双箭头 | 可补偿的活动 |

### 网关 (Gateways)

网关控制流程的分支和合并：

| 网关类型 | 符号 | 分支行为 | 合并行为 |
|----------|------|----------|----------|
| 排他 (XOR) | X | 只选一条路径 | 任意一条到达即继续 |
| 并行 (AND) | + | 所有路径同时执行 | 等待所有路径到达 |
| 包容 (OR) | ○ | 选择一条或多条 | 等待已激活的路径 |
| 事件 (Event-Based) | 五角星 | 根据事件选择路径 | 不适用 |
| 复杂 (Complex) | * | 自定义条件 | 自定义条件 |

## 连接对象 (Connecting Objects)

### 顺序流 (Sequence Flow)

连接同一池内的元素：

| 类型 | 样式 | 用途 |
|------|------|------|
| 普通顺序流 | 实线箭头 | 正常流转 |
| 条件顺序流 | 实线+菱形 | 带条件的流转 |
| 默认顺序流 | 实线+斜杠 | 默认路径（无条件匹配时） |

### 消息流 (Message Flow)

连接不同池之间的元素：
- 样式：虚线 + 空心圆 + 箭头
- 用途：表示跨组织/参与者的通信

### 关联 (Association)

连接数据/注释与流程元素：
- 样式：点线
- 方向：无向、单向、双向

## 泳道 (Swimlanes)

### 池 (Pool)

- 表示流程的参与者（组织、系统、角色）
- 池之间只能用消息流连接
- 可以是"黑盒"（隐藏内部细节）或"白盒"（显示内部流程）

### 泳道 (Lane)

- 池内的细分
- 表示部门、角色或系统组件
- 可以嵌套多层

## 数据元素 (Data Elements)

| 元素 | 形状 | 用途 |
|------|------|------|
| 数据对象 | 折角文档 | 流程中使用的数据 |
| 数据输入 | 折角文档+空心箭头 | 流程的输入数据 |
| 数据输出 | 折角文档+实心箭头 | 流程的输出数据 |
| 数据存储 | 圆柱体 | 持久化存储 |
| 数据集合 | 三文档 | 数据对象的集合 |

## 人工制品 (Artifacts)

| 元素 | 用途 |
|------|------|
| 组 (Group) | 可视化分组，无执行语义 |
| 注释 (Text Annotation) | 提供额外说明信息 |

## 元素层级关系

```
流程定义 (Process)
├── 池 (Pool)
│   ├── 泳道 (Lane)
│   │   ├── 开始事件 (Start Event)
│   │   ├── 活动 (Activity)
│   │   │   ├── 任务 (Task)
│   │   │   └── 子流程 (Subprocess)
│   │   ├── 网关 (Gateway)
│   │   └── 结束事件 (End Event)
│   └── 顺序流 (Sequence Flow)
├── 消息流 (Message Flow)
├── 数据对象 (Data Object)
└── 人工制品 (Artifact)
```
